# Anthropic default Skills

The 17 Skill directories in this folder were vendored without modification from:

- Repository: https://github.com/anthropics/skills
- Source path: `skills/`
- Commit: `1f630fdf9259cec4a14913127dfd7c3b69ef72eb`
- Imported: 2026-07-24

Each Skill keeps its upstream `SKILL.md`, scripts, references, assets, and license files. The
repository-level third-party notices are preserved in `THIRD_PARTY_NOTICES.md`.

Licensing is not uniform. Most directories include an Apache 2.0 `LICENSE.txt`. The `docx`,
`pdf`, `pptx`, and `xlsx` directories contain Anthropic source-available license terms rather
than an open-source license. The upstream `doc-coauthoring` directory does not contain a
directory-level license file. Review the terms in each directory before redistribution.
